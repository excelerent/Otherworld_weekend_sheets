# Project Goal: Party Tracker Sheet Creator (Google Sheets)

Our goal is to create a tool to be used by staff members during the event to enter information about the party and their progress throughout the weekend. This tool will generate a Google Sheet using Google Apps Script.

## Inputs
We will take in information from the following JSON files (generated by other exporters):
* `PartyPaths.json`: Contains the encounters for each party.
* `ChargeTable.json`: Contains the charge information for each party.
* `Parties.json`: Contains general information about each party (Companion, Staff Member, Background Color, Table Color, Text Color).

## Output
A Google Sheet created via Google Apps Script. The script will be written in TypeScript and converted to Apps Script using `clasp`.
When rebuilding the sheets, all created sheets should be deleted, and the script should be re-build them.

### Party Sheets
Each party will have 2 sheets:
* `Import Sheet`: Named "{Party Name}_Import", will be used to import data from The Party Path Tracker Sheet. 
  * There is a script in the Party Path Tracker Sheet that will automatically populate this sheet.
* `Party Sheet`: Named "{Party Name}_Party Sheet", this will output visual information, drawn from the output sheet (above)
  * The tab should be colored the same as the party's background color.
  * Title Section:
    * The top row will be the party name, bold, in 27pt font, colored black, with the background the same as the party's background color
    * Freeze the top row.
  * Info Section (starting after Title Section):
    * Row 2 with black text and a white background at 10pt font: "Investigating the charge against: {Charge Name}"
    * Row 3 with black text and a white background at 10pt font: "Companion: {Companion Name}"
    * Row 4 with black text and a white background at 10pt font: "Keepers Saturday Morning dream :{keeper saturday morning dream}"
    * Row 5 with black text and a white background at 10pt font: "Riddle: {Riddle summary}"
    * Row 6 with black text and a white background at 10pt font: "Keepers Sunday Afternoon dream: {keeper sunday morning dream}"
  * Party Path Table (starting after Info Section, on column A):
    * should span from A:8 to D (4 columns) with information filled out by the PartyPath.json
    * Columns:
      * Complete: Yes! / No, pulled from the "Gave Item/Info" (True/False) column (B) of the PARTY PATH table in the Import sheet. text should be centered and bold.
      * Staff: staff member name (from PartyPath.json) bold
      * Time: Time from the PartyPath.json
      * Items to Give: Items from the PartyPath.json, if no item, use "--".
    * Formatting:
      * Title Row: 4 columns: Complete?, Staff, Time, Items to Give, bold and centered.
      * The entire table, save for the title row: should be surrounded by a black 2pt border.
      * If Complete is Yes!, the entire row should be colored green (#b7d7a8), and the Yes! cell should be colored dark green (#6aa84f)
      * If Complete is No, the cell for Complete should be colored red (#f7a8a8), but the rest of the row should be white.
  * Charge Table (Starting after the Info Section, on column F)
    * Should span from F to I (with a hidden J column used for calculations)
    * Each piece of charge information should be a row in the table.
    * Overview:
      * The charge table is slightly different in the EM dashboard than in the Party Path Tracker Sheet.
      * Here each bloc of charge information has several pieces of information. each charge giver should be a separate row, but each bloc should have a merged row for Info to Give and Bloc Requirements.
    * Columns:
      * Complete?: Yes! / No pulled from the "Gave Info" (True/False) column (B) of the Charge info table in the import sheet. text should be centered and bold.
      * Staff: The staff member who gave the info (from ChargeTable.json). bold.
      * Info to Give: Info to give (from ChargeTable.json)
      * Bloc Requirements: Formatted as "Need X" (from ChargeTable.json) of Need (if there is only 1 row in the bloc)
    * Formatting:
      * Each row (Complete columns) should be colored dark green (#6aa84f) if the charge is complete
      * Each row (Staff column) should be colored green (#b7d7a8) if the charge is complete
      * Each row (Complete and Staff columns) should be colored red (#e06666) if the charge is not complete
      * The merged Bloc Requirements column should be colored red (#e06666) if the party does not have enough information to give the charge.
      * The merged Bloc Requirements AND the merged Info to Give column should be colored dark green (#6aa84f) if the party has enough information to give the charge.
      * To determine if the party has enough information to give the charge: the total number of items in the Info to Give column should be greater than or equal to the number of items in the Bloc Requirements column., use column J for this calculation.
      * There should be a black 2pt border around the entire table.
      * There should be a black 2pt border around blocs of charge information.
  * Comments Section (starting after the Party Path Table):
    * The title of the section should be "Comments"
    * Comments from the Import Sheet should be added to this section
    * Each comment will occupy a single row, and each row is a horizontally merged cell of rows A to D (4 columns)
    * Take from the notes section of the Import Sheet.
      * From the party path table (column C)
      * From the charge table (column C)
      * From the general notes section (column A)
      * Skip any empty rows.
    * Use an in-cell formula to manage this.
    * The comments section should be surrounded by a black 2pt border.
  * For each party sheet the columns should have the following widths:
    * A: 80px
    * B: 120px
    * C: 120px
    * D: 150px
    * E: 20px
    * F: 80px
    * G: 120px
    * H: 300px
    * I: 80px
    * J: 1px
